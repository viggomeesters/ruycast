# Rust source export

Build the source tool with `cargo build --locked --manifest-path rust-native/Cargo.toml --bin ruycast-source`. This requires Rust and the macOS SDK, not a Swift compiler or Swift host. The unchanged system `/usr/bin/gzip` compresses/decompresses the Rust-generated canonical USTAR stream with no timestamp or filename metadata.

Run `ruycast-source export --repo /absolute/source --out /absolute/staging/new-name`. The tool creates a clean directory, sibling `.tar.gz` and `.tar.gz.sha256`, without replacing existing paths. Missing staging parents are created through no-follow directory descriptors. `ruycast-source verify --source /absolute/staging/new-name` verifies a clean export without Git or `.go`. Add `--repo /absolute/source` to also compare it with the trusted original source. Keep Cargo build output outside a clean export (for example with an explicit external `CARGO_TARGET_DIR`). `list --repo` returns the exact selected paths. The Python `prepare-public.py` entrypoint is only a compatibility dispatcher.

`PUBLIC-SOURCE.json` schema `ruycast.public-source.v2` records sorted SHA256 files, normalized POSIX modes, roles and the compiled Rust product version. The same names, bytes and modes produce the same USTAR and gzip bytes for a given gzip toolchain. The version, public default configuration, source-tool implementation and allowlist must exactly match the bytes compiled into the tool; rebuild after changing them. The receipt contains no absolute source paths, user IDs, timestamps or private workflow state. It is an integrity receipt, not a signature or publication proof; use the independently trusted release checksum for authenticity.

The explicit allowlist is `rust-native/src/bin/ruycast-source/policy.rs`. New product/test files must be reviewed and added explicitly. Unreviewed paths inside the Rust product-source trees are refused rather than silently omitted. Unknown other files, examples/staging merge helpers, `.go`, profiles, private adapters, signing keys, build output and GitHub Actions are never auto-discovered or copied. Source reads anchor each component to no-follow directory descriptors and reject links, hardlinks, special files, oversized files and signing/key material. Source identities/bytes are rechecked after staging. Concurrent mutation detected during copying refuses the export; this is not a filesystem snapshot against a malicious same-user writer after the final check.

`Sources/`, `Package.swift` and `Tests/LauncherCoreTests/` are frozen historical Swift references and test oracles. They are explicitly marked in the manifest and are not a supported Swift production build. The product host, CLI and new tooling build from `rust-native/` and `rust/`. Historical test/build scripts remain references while the coordinator completes Rust delivery integration. Exporting a candidate does not accept the entire rewrite, publish a release or install anything.
